# Seed Soul — G13 baseline

This is a compact, provisional computational projection of POC_SPEC 8.1.
The nine pattern names and six degradation pairs come from the supplied
original Soul architecture (section 4). Descriptions specialize the current
Constitution and do not reproduce or claim the unavailable full v1.4 compass.
The ratified 26.3 role grammar is not identified with nine separate substances
or reduced to a score.

A fixed trusted bootstrap imports data-only soul.metta into &soul.
src/soul.metta reads doctrine; it has no ordinary writer into that space.
SoulRequire and SoulPairRequire are actual native obligation consumers:
missing or contrary witnesses block them, including either missing partner.
These internal symbols are not self-authenticating evidence. Later movement
and voice gates must obtain their witnesses from the appropriate verified
sources before invoking these guards.

Startup requires both byte/loaded-atom integrity and a native rationality
audit. Each declared value/relation must resolve to one live causal procedure,
which must accept its positive witness and reject a contrary one. An unresolved
procedure is not treated as success. Diagnostic snapshotting never updates the
trusted pin. The manifest also pins the native consumer and hashing code.

This establishes the immutable baseline, not a sandbox for arbitrary MeTTa
programs. A trusted host can still change files or use PeTTa mutation primitives.
Untrusted candidate isolation and writer attacks must be proved separately in
G23 and G27. No generated MeTTa may be evaluated in the core.
