## Native organization

There is no “qwen failure means Nemotron” behavior entry and no first-match order. Reordering inventory must preserve the result; removing Nemotron must hold; marking qwen's relevant defect defeated while restoring its grant must create an unresolved comparison rather than silently prefer either model.

The bridge request receives the exact R2 bridge and test consequences plus concise valid SWI-Prolog representation examples. The test request additionally receives the newly returned bridge product so it can target the declared behavior without weakening the contract. The LLM renders only source. MeTTa owns resource choice, targets, assembly, qualification, and continuation standing. Prolog owns local transport, exact durable evidence, quarantine, syntax, and process mechanics.
