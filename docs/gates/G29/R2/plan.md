# G29 R2 — native evidence-selected two-part repair

## Bounded claim

G29 R2 preserves the source-grounded design, manifest, rationale, plan, and all R1 failure evidence. Native MeTTa relates observed violations to artifact obligations and selects only the bridge and test files whose obligations were defeated. The local semantic organelle renders those two replacement files; it neither chooses the repair scope nor qualifies its output.

Passing R2 proves a quarantined Miter-authored Mattermost design and candidate suitable for the independent G30 mock round trip. It does not prove live Mattermost behavior, production readiness, complete Soul cognition, or permission to activate or promote the bridge.

## Constitutive fit

The repair is consequence-sensitive rather than a blind retry: the preserved test contact changes what is generated next. Artifact/obligation relations, not error-name behavior entries or first-match rules, determine the repair targets. The fixed design and passing design product are not regenerated. Prolog performs model transport, durable evidence, syntax/test process mechanics, and boundary scanning; MeTTa owns target formation, assembly, comparison, and continuation standing.

The LLM is a semantic renderer. Its files remain candidates until exact lineage, native qualification, actual PLUnit execution, adversarial controls, and independent verification agree. No generated file can change its grant, modify the cognitive core, contact Mattermost, access Chroma or Soul directly, introduce credentials, or certify itself.

## Frozen experiment

1. Reopen from the committed R1 evidence and exact candidate hashes. Admit typed observations for bridge syntax/export failure and invalid test structure, plus artifact-to-obligation dependency relations.
2. Show natively that violated observations select both affected artifacts; swapping evidence swaps the selected target, unknown evidence remains unresolved, relation reordering is neutral, and severing the dependency defeats selection until restoration.
3. Spend at most two new qwen-local calls: one bridge repair and one test repair, each capped at 2,048 output tokens and 300 seconds. Supply the old source, exact diagnostics, unchanged public predicate contract, and no credentials or network authority.
4. Assemble the retained design product with the two exact replacement products. Materialize only in a new `mattermost-r2` quarantine path.
5. Require the corrected syntax verifier to pass both files and run the candidate-authored PLUnit suite. A zero process exit is insufficient when stderr contains an error. Preserve stdout, stderr, status, hashes, prompts, streams, and timing.
6. Run independent structural and causal controls. Missing identity, direct core access, credential-shaped literals, syntax failure, test failure, foreign path, severed product, and evidence/target mismatch must prevent qualification. Reordering independent evidence or files must not change the result.
7. Produce a G29 closure and a separately frozen G30 plan only if the revised candidate passes. Do not promote, activate, or contact Mattermost in G29.

## Resource and stopping conditions

This slice permits at most two new local calls, 2 MiB capture per call, no persistent model changes, no remote provider, no live Mattermost request, and no credentials. If either response is incomplete or the revised candidate still fails, retain the evidence and compose a new bounded plan from the changed consequence; do not silently increase the grant or hand-edit model-authored candidate code.

G29 completion remains limited to authored design/candidate provenance and bounded local contract evidence. G30 independently tests duplicate delivery, edits, authorization ordering, idempotent effects, witnessed failure, reconnect, restart cursor, panic, and severed controls against a mock service.
