## Integration risks actually found

1. **Overlapping operator families and unproven namespace isolation.** The pinned libraries overlap beyond `Truth_Revision` and `|-`. PeTTa source-atom spaces and compiled function dispatch are not shown to share the same isolation boundary. The integration plan specifies qualified transitive operator closures and execution/load-order tests before use. This audit establishes a source-level hazard, not a measured collision outcome.
2. **Truth-value meaning can be silently conflated.** Historical examples use similar numeric shapes and imply mappings. Current controls require an explicit semantic contract; no automatic PLN↔NAL↔p-bit conversion or inherited thresholds.
3. **Freshness can be fabricated by derivation.** New conclusion IDs, repeated model text and alternative proofs of the same source do not provide fresh independent support. Preserve source-family overlap before revision, not as an afterthought to a confidence score.
4. **More inference can conceal the existing semantic gap.** A correct deduction from an unsupported interpretation does not establish an actual human/interface condition. Grounding and independent contact remain load-bearing.
5. **Broad imports can add unnecessary search and nondeterminism.** Select the intended operation; measure cardinality, cost and relevance. Do not route NAL revision through an unconstrained `|-` search or saturate every AtomSpace on every cycle.

## Recommended sequence and omission control

1. Commit this plan and audit separately from unfinished SC06 implementation. Preserve all controls, archives and G22 work.
2. Resume and close only SC06's frozen claim; derive its readiness/next-prerequisite assessment from actual evidence.
3. At the next affected planning boundary, select the earliest unmet useful inference obligation. For each selected PN row, freeze exact source meaning, operator isolation, truth/evidence semantics, consumer and causal experiment before integration.
4. Prove one thin native vertical slice, including absence/severing/restoration and independent readback. Expand only where evidence shows useful constructive capacity or necessary efficiency. Keep G24/G25's mandatory native NAL and later-selection claims explicit.

This improves efficiency by reusing the already built provenance and undertaking spine. It avoids both indiscriminate library integration and endlessly postponing useful inference behind general aspirations. Stable PN identifiers and explicit revisit triggers make omission visible; they do not become rules selecting Miter's behavior.
