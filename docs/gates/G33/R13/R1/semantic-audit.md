# G33 R13 R1 semantic audit

R1 creates no new cognitive standing. It corrects the evidence-version
relationship needed to review an intentional default upgrade.

R12 remains a historical runtime claim bound to the exact source and evidence
bytes it executed. R13 remains a current runtime claim bound to the promoted v2
default and its independent verifier. The old verifier's rejection demonstrates
that those versions are not silently conflated; Git-object verification shows
that the historical bytes have not disappeared or been rewritten.

The compact R13 proof remains causally grounded in native trial, consequence,
NAL/NACE and ranking consumers. This package does not infer semantic validity
from matching hashes, claim v1/v2 equivalence, generalize the synthetic case,
or treat version-aware provenance as final G33 integration.
