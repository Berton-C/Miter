The versioned v2 bootstrap loaded, but preflight stopped before cognition. The
R13 prefix had been added to `dh_root/2` while `dh_no_links/1` still terminated
only at the R12 evidence root. Canonical R13 was therefore rejected; canonical

rejected. No model, credential, live service, candidate trial, persistence, or
external effect occurred.

The generic repair is to add the exact R13 evidence root as the second
recursive no-symlink base case. No broader prefix or path class is admitted.

## Attempt 002 — ordinary input failure was not totalized

R14 root rejected. Canonical and reverse-manifest inputs were byte-for-byte
equivalent. The deliberately false candidate hash caused `dh2_input/2` to fail

The repair makes both ordinary validation failure and exceptions return the
same typed `development-helix-v2-input-unavailable` state. It does not admit

file was 4 KiB instead of R12's 81 MiB and retained canonical hashes, an

copies. The 13/four counts are corrected from the committed R12 trial itself;
no case, report, decision, or acceptance condition changes.
