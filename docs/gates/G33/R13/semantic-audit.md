# G33 R13 semantic fidelity audit

The compact proof is not a host-generated synopsis. Native PeTTa/MeTTa still
constructs both full trial reports, validates them, performs non-compensatory
adjudication, observes typed consequences, invokes pinned NAL revision, and
ranks the same two eligible alternatives. Native projection relations choose
the material fields. Prolog only canonicalizes/hashes ground terms and commits
the exact staged native witness.

The result preserves causal bite: the canonical arm changes from two maxima to
the generated candidate alone, while the exact-candidate consequence-severed
arm remains tied. Reverse manifest ordering is neutral. Restored persisted
consequence rehydrates the candidate-only maximum without replaying generation.

The representation repair is material operationally. R12 nested the same large
reports/rankings in several artifacts and could not return cleanly after final
serialization. R13 stores the native-selected proof once in compact form, and
the same recurring process observes stop and exits cleanly. This does not make
hashes semantic authority, generalize the one synthetic trial, or prove final
G33 integration.

The old R12 verifier's source-hash failure is not concealed or relabelled. Its
historical freeze is correct, but it is not a current-version regression test.
The next package must check the R12 bytes against their historical commit and
the promoted v2 path against current R13 evidence. Until that version boundary
is explicit, closure remains incomplete despite the passing runtime.
