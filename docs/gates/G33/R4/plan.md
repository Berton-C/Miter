# G33 R4 — capability-limited relational voice runtime membrane

R3 found that corrected relational voice cognition exists as pure native products but its public entry is confined to a historical SC05 evidence directory. R4 repairs only that non-cognitive membrane.

The replacement uses two explicit inputs in a fresh runtime root: a narrowly scoped runtime grant and a source-integrity manifest. The grant fixes the canonical root, request and scope, localhost model, single-call budget, expiry, purpose, and absence of human-emission authority. The manifest pins every required control, native module, membrane, and non-secret model profile. Prolog may validate these facts, confine fixed mechanical outputs, perform the localhost request, and retain bytes; it may not form the intention, interpret language, judge fidelity, repair an expression, certify a movement, or emit to a human.

The historical SC05 membrane remains unchanged. The current bootstrap moves to a versioned v2 membrane so old evidence retains its exact implementation identity. Invalid, overbroad, stale, mismatched, or tampered authority must fail before transport. One actual synthetic qwen-local rendering is sufficient for the bounded positive claim.

This does not repair the next cognitive gap. If the public entry exposes a repair request with no native continuation, that becomes a separately frozen R5 problem rather than being smuggled into this mechanical gate.
