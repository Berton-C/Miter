# G33 R2 — source-grounded continuity reading repair

G33 R1 found a real constitutive discontinuity: the exact capsule and trajectory machinery was reachable only after a hard-coded equality test against one sentence. That is not the ninety-day continuity described by S-803 or T-19. R2 repairs only that seam.

The authenticated message is direct contact. Its interpretation is not. Miter may ask the local model for a bounded reading, but the product remains generated, fallible, and inert. It must cite exact spans from the contact and state the project-kind relation and continuity facets it believes those spans support. The membrane verifies structure, identity, source hash, and literal span correspondence; it does not select meaning.

Native MeTTa then decides whether those generated relations are sufficient to form a continuity continuation. It requires verified source participation, at least one supported continuity facet, and exactly one project of the proposed kind within the already authenticated principal and audience scope. Only that native composition can reach the existing capsule reconstruction and trajectory witness. The model never names the project ID and never supplies checkpoint content.

This is deliberately not a synonym list, intent classifier score, first-match rule, or canned answer. It is also not a claim of general language understanding. The R1 paraphrase is now known to the builder, so R2 calls it a transfer/regression case. A genuine held-out wording can be supplied only after the implementation is frozen.

R2 uses at most two bounded `qwen-local` calls per attempt, entirely on localhost and over synthetic fixture text. It makes no Mattermost, OpenRouter, Keychain, external-network, Chroma-write, or other external effect. Failures and partial products remain evidence rather than admitted continuity.
