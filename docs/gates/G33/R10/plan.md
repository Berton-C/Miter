# G33 R10 — source-grounded development enters the recurring reactor

## Bounded claim

A dedicated current bootstrap combines the existing recurring reactor with the
R9-qualified development graph. Starting from an empty ready set, the reactor
may read a typed raw contact bundle through a mechanical Prolog membrane; native
MeTTa must construct the audits, opportunity, `CStep` result, and bounded RNA.
The resulting undertaking and unapplied effect request persist durably, then the
RNA reaches an explicit waiting boundary without any model call or external
effect.

The test harness may create disclosed input files, start/stop processes, and
inspect results. It may not invoke `DObserve`, `DOpportunity`, `DDevelop`, or
`CStep` as a stage command, write a development opportunity/RNA/decision, or
turn an expected label into native standing.

## Causal and continuity evidence

Fresh canonical, source-order-neutral, same-family, self-authored,
missing-capability, and exhausted-grant roots run independently. Only a native
qualifying result may transcribe the new development RNA. The held arms must
retain their differentiated native reasons without manufacturing an
undertaking. Restarting the canonical root must preserve the exact state and
effect-request bytes, rehydrate no already-waiting work, and append no duplicate
development decision. Explicit direct-contact stop must terminate every driver.

## Boundary

R10 adds a narrow bootstrap, MeTTa promoter/advancer, and Prolog contact and
persistence membrane. Prolog validates shape, converts JSON/native terms,
hashes, performs write-once persistence, and appends already-formed products; it
does not select purpose, interpret flourishing, form an opportunity, or decide
whether an RNA is warranted.

The historical `InterestIdle`/`DevelopBoundary` pair remains preserved and is
not loaded by this dedicated bootstrap. R10 does not yet replace the default
`bootstrap_modules.metta`; doing so before this experiment would mix the
corrected path with the known fixed-proposal path and erase the causal
discriminator. Default-bootstrap reconciliation is a later revision if R10
passes.

No candidate generation, trial, promotion, model, Chroma, Mattermost, history
retrieval, private memory, credential, human emission, or external effect is
authorized.
