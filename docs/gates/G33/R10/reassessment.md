# G33 R10 control-document reassessment

R9 repaired the public semantic dependency graph but intentionally stopped
before recurring integration. R8 had already proved the precise remaining
discontinuity: direct native calibration could form the corrected opportunity,
while the recurring reactor exposed only the older `InterestIdle` and
`DevelopBoundary` hooks.

The Constitution places meaning-bearing cognition in PeTTa/MeTTa (C-004,
C-060–064), requires material counterfactual bite (C-011–012), and distinguishes
persistent readiness from perpetual inference (C-070–075). The Soul
specification adds that transcription must follow a grounded undertaking
(S-602), lifecycle transitions must mean something (S-604), the native driver
must recur independently of model calls (S-606), and the undertaking must
survive bounded execution slices (S-607).

Accordingly, the most leveraged next experiment is not another direct semantic
probe and not a model call. It is the missing composition boundary itself: raw
contact reaches the recurring engine, current native relations determine
whether an undertaking exists, and the resulting state survives a restart. A
dedicated bootstrap keeps that causal claim inspectable. Loading the historical
fixed proposal in the same run would make it impossible to tell which mechanism
originated development.

This remains a finite capability experiment. The existing `DOpportunity` family
is still limited to a VoicePolicy retention-omission surface, and `CStep` still
constructs one bounded generation request shape. Passing R10 would show that a
source-grounded native undertaking can enter and survive recurring cognition;
it would not show general purpose formation, complete Soul navigation, or
open-ended self-development.
