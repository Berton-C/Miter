# G33 R1 — Clean-start constitutive end-to-end experiment

## Why this is the next gate

G32 now proves a bounded integrated severed-arm matrix using products returned by selected current consumers. It deliberately does not prove that those consumers form one organism from a clean process start. G33 is therefore the next unmet dependency in both `ACCEPTANCE.md` and the governing claim in `README.md`.

This plan rejects two shortcuts:

1. It will not run unrelated historical gate scripts and call their collected PASS labels one cognitive trace.
2. It will not add a builder-authored stage machine that tells Miter which semantic state to produce next.

The experiment supplies contact, observations, constrained resources, and deliberate faults. Current PeTTa/MeTTa consumers must produce the meanings and next continuations. Prolog may perform only the already bounded mechanics. The launcher and independent verifier may retain and compare products but cannot choose them.

## Frozen claim

One top-level G33 execution begins with an empty G33-owned runtime root, observes deliberate process restarts, and produces a causally connected trace for exact continuity, native voice repair, receptive readiness, witnessed development, governed capability trial, consequence-earned NAL revision, later selection, restart-preserved lineage, and the Miter-authored Mattermost extension/use chain. The same run performs the required five integrated severances and meaning-preserving controls. A separate verifier renders `FINAL_POC_REPORT.md` clause by clause.

The detailed precommitted phases and failure conditions are in `expected-run-contract.json`. The prerequisite ledger records prior evidence without treating it as the G33 result.

## Live-boundary interpretation

The prior G31 grant ended in terminal panic and its live canary is immutable historical evidence. G33 may validate and incorporate that hashed witness into the complete evidence package, but it must not describe it as a fresh G33 effect. This plan grants no new Mattermost access. A genuinely new live canary would require another exact C-098 grant after its scope is surfaced.

## First experiment boundary

R1 may build only the integration fixture, launcher, independent verifier, G33 evidence, and generated final report. It may not modify Miter core. That boundary is intentional: if the existing build does not compose, the failure should identify the actual missing semantic seam before a repair is designed.

The test must use a held-out book-continuity wording and a relational expression not named in a current dispatch table. Exact-prompt routing, stage labels, expected witness words, prior verdicts, or host-selected answers cannot pass.

Even a PASS would establish only the bounded two-part PoC claim and the mechanisms named in acceptance. It would not establish final Soul mathematics, universal intelligence, complete multi-user governance, unrestricted safe self-programming, or guaranteed success for arbitrary future extensions.
