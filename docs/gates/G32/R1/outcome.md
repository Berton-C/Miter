# G32 R1 outcome — harness proven, gate not closed

G32 R1 produced a useful but insufficient result. Attempt 004 passed its independent builder verifier across 28 fresh native processes: eleven declared material severances, eleven restorations, neutral and decorative controls, a held-out meaning-preserving case, a non-recursive oracle boundary, and a 32-wait zero-pitch reactor run. The zero-pitch arm made no model call or effect and did not claim completion. All R1 attempts made zero network requests, credential lookups, model calls, external effects, or persistent runtime mutations.

The failed attempts remain part of the evidence. Attempt 001 exposed overlapping VAD fixture clauses and four native products where one was required. Attempt 002 exposed PeTTa empty-superposition behavior: an absent participant silently killed a result corridor instead of producing an explicit held standing, consistent with W-027 through W-029. Attempt 003 exposed a verifier representation error in which parsed MeTTa numeric atoms were compared as JavaScript numbers. Those defects were repaired only in the test fixture and independent verifier; Miter core was not changed.

The mandatory control-document review then found that the green attempt 004 could not support R1's strongest claim. The canonical probe did execute nine current native consumers, but the arm composer did not consume their returned products. It consumed source- and evidence-hashed `participant ... available` records assembled by the builder. Removing one of those records caused the generic native dependency composer to report a missing relation, which demonstrates the harness and its differentiated semantics but does not yet demonstrate causal severance of each actual subsystem consumer.

Closing G32 on that basis would violate C-100/C-103 and S-504/S-1101/S-1201–1203 by substituting a provenance-bearing declaration for the runtime relation it describes. R1 is therefore **not closed** despite its `PASS-BOUNDED` harness verdict. The useful fixture mechanics, expected matrix, raw probes, neutral controls, and zero-pitch result are retained. G32 R2 must move each material perturbation upstream of the relevant actual native consumer and construct the observed arm matrix from that consumer's returned standing and derivation trace. No G33 work may begin until that stronger G32 claim passes.
