# Bounded native voice

G16 proves five declared intentions: compassionate boundary, technical answer,
emerging insight, minimized tension, and a neutral request. This is a closed
seed expression grammar, not unrestricted natural-language adjudication.
The model selects and orders approved wording variants. It cannot add unchecked
prose or change the task distinction, scope, uncertainty or required meaning.

The trusted bootstrap loads native intention construction, the fixed grammar,
AuditRNA, movement construction and the mechanical membranes. No model output
is parsed or evaluated as MeTTa, shell or executable code. The grammar is fixed
seed code; its later evolution would require the separate candidate lifecycle.

Each candidate is structural JSON first, then a native audit target. Thirteen
named defect checks enforce exact clause membership, exactly one clause per
required group, person/agency/tension/scope presence, uncertainty, authority,
coercion, bounded length and VAD output-register limits. Missing meaning and
unsupported additions fail closed. The deterministic grammar supplies the
semantic guarantee for these fixtures; keyword checks alone do not claim it.

VAD checks rendered text under rendering provenance, not external-contact
standing. Its coarse register cue cannot change task permission. A deliberately
injected register band proves that the register audit changes admissibility.
The complete direct-contact G15 fixture remains passing after this extension.

A passing audit is still not emission. Native Soul integrity and the G14
witness-first movement constructor must pass. The resulting CertifiedUtterance
binds intention, candidate, audit, movement and text hashes. The local test
surface rechecks those hashes and standings. Duplicate delivery is idempotent;
tampered or uncertified text is withheld. Actual local file emission is recorded
as an action-result event in the append-only trajectory.

The local provider uses the G05-proven non-reasoning decoding setting. A fixed
SWI-Prolog worker performs transport; a parent-side deadline can terminate and
reap that worker without stopping LM Studio or any user service. G16 allows a
first candidate plus one repair. G17 separately proves exhaustion and fallback.

No Mattermost adapter, bot, credential, external human message or unrestricted
speech path is introduced by this gate. The surface here is an isolated local
test directory, not a claim of a complete interactive assistant.
