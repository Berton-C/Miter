# G15 — PASS

## Requirements and mechanism
G15, POC_SPEC 10, C-050–053/060–062, W-070–075. Prolog validates the local
NRC v2.1 checksum and source-event bytes, tokenizes, chooses longest exact
multi-word matches before unigrams, and optionally performs bounded suffix
normalization only after exact miss. PeTTa/MeTTa performs aggregation, coverage,
trajectory, presence selection and permission-dependency adjudication.

## Observed results
Fourteen synthetic phrases produce fourteen ordinary cues plus one
lexicon-severed cue. The pivot has improving-pivot and changes presence to
preserve-emerging-insight. The minimized phrase retains an ambiguous lexical
trajectory and separately reports minimization-pressure-cue. Positive ending,
missing minimizer, reversed clause order and a second minimization sentence
are discriminating controls; no lexical threshold was adjusted to pass them.
Absent and ten-percent coverage yield insufficient-coverage, never neutral
certainty. Identity terms are conservatively excluded. Real MWE lookup and a
separate wholly synthetic overlapping-MWE probe both pass.

All cues remain affective-language-cue, with no diagnosis or inner-state claim.
The bad mock permission function changes permission across affect values; the
native dependency gate rejects it. The canonical TaskPermission signature has
only authenticated scope and task facts. Presence has a separate causal branch.
