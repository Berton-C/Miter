# G16 — PASS

## Requirements
G16; POC_SPEC 11; C-004/006/009/020/023/050–057/060–062/100–104.

## Proven path
Five native CommunicativeIntentions were written before rendering. Six real
Qwen responses were obtained: five ultimately accepted responses and the
original first boundary response, which was preserved before fault injection.
The injected candidate was explicitly labeled as test data, not attributed
to Qwen. Native AuditRNA rejected it with six named defects. A defect-specific
real-model repair then passed. The other four real renderings passed directly.

Each final emission has a passing native audit, verified Soul integrity, a
G14 movement certificate, a hash-bound CertifiedUtterance and separately
verified text bytes on the local test surface. The ledger verifies at 53 events,
including five witnessed emission results. Five repeated emissions are
idempotent and leave the trajectory unchanged. The bad original and a modified
copy of an accepted candidate are both blocked. The deliberately audit-severed
test surface receives the bad text and is never imported into production.

All thirteen specified defect names have a discriminating synthetic probe.
The register-only probe changes a measured cue's dominance band in a labeled
test copy, preserves the original, and causes affect-register-mismatch. Source
provenance remains rendering. The complete G15 direct-contact regression passes.
Structural probes reject a changed intention ID, extra model task-verdict key,
and malformed clause list. The final implementation independently re-audits all
five accepted candidates without defects.

## Failures retained and corrections
The first two service requests failed because the new request omitted G05's
reasoning_effort: none setting. The initial cold-start explanation was an
incomplete hypothesis. Server timing shows the warm request used all 1024
tokens for reasoning and produced no answer. The corrected request completed
in 10,624 ms. Native HTTP signal delivery exceeded the nominal time limit;
the fixed worker deadline now kills and reaps an over-budget owned child.
Its 5-second sleep control was stopped in 0.362 seconds with a 0.25-second
deadline plus bounded reaping, while a normal child completed successfully.
No user service was stopped for these tests.

An intention probe exposed two scalar matches accidentally sharing the same
MeTTa variable; distinct bindings fixed the empty result. A later probe refined
duplicate-group diagnostics: duplicates violate exact coverage but do not mean
the person is absent. Earlier raw results are retained. All five final accepted
candidates remain passing under the corrected audit.

## Explicit bounds
This is an explicitly closed, fixed clause grammar for five intentions. It
proves bounded native semantic control, render–audit–repair and emission, not
general semantic understanding of arbitrary prose. The fixture source facts
and internal-only action scope are fixed independently of the model. Movement
witnesses are populated only after native audit passes; they do not grant live
external reach or certify unrestricted model text.

Protected files and the G13 Soul baseline remain unchanged. No Python is used
in the core path. NRC rows and per-term numeric scores are not exported. No
Mattermost implementation or live communication was added. The legacy services
and their persistence were not changed by G16.
