qualifying fixtures, but current `DObserve` returned an unreduced `RAudit`
inside each receipt. `DRead` therefore classified both receipts as

files once in dependency order—grounded language, then relational voice, then
development evidence—returns `development-opportunity` for the exact same

made `bootstrap_relational_voice.metta` import `development_evidence.metta`
before `relational_voice.metta`; the former therefore captures an unresolved
`RAudit`. Its caller `bootstrap_voice_construction.metta` imports development

precedence. The full development bootstrap also loads the legacy
`miter_relational_voice.pl` over the current v2 membrane through
`miter_voice_construction.pl`, producing explicit static-predicate redefinition
warnings.

The recurring process did stop explicitly and made no model or external call.
Its registered hooks were only historical `InterestIdle` and
`DevelopBoundary`; no corrected development hook was present. That observation
is retained, but it is downstream of the failed native calibration and is not
yet the R8 first discontinuity. A repair must first restore one acyclic,
dependency-ordered public bootstrap and remove the legacy/v2 membrane collision;
only then can the missing corrected reactor hook be tested and repaired.
