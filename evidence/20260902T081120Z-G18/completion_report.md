# G18 — event reactor and quiescence

A persistent PeTTa process ingests a local human event and a due obligation,
transcribes three finite RNA instances across the later wake, and records
Transcribe, Inquire, Witness and Consolidate loci. Its actual bounded action
hashes the durable ledger. This is a plumbing fixture, not a claim of general
research. Empty ready sets record quiescent-ready once per idle episode and
wait on file-backed ingress. A later contact wakes the same process. An explicit
stop event ends it normally; the parent verifies exit and the complete ledger.

A synthetic continue-autonomous-work event without a witnessed obligation is
rejected, creates no RNA and leaves the reactor quiescent. No model transport
is in this reactor's import/call graph; the zero call count is structural, not
inferred from model text or from a server-wide counter shared with other apps.

Two failed runs are retained: an untagged tuple collided with PeTTa's first
function, and a subtraction expression stored literally in AtomSpace needed
evaluation before insertion. Tagged data and a bound numeric budget corrected
both. Canonical and negative runs then completed normally.

Local file ingress is trusted harness transport, not an authenticated external
surface. Priority, interruption and increasing idle intervals are G19 work.
No user service, protected document, Soul baseline or licensed asset changed.
Rollback is a revert of this additive gate, retaining its evidence.
