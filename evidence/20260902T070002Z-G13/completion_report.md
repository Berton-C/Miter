# G13 — PASS

The pinned native PeTTa runtime loads 78 atoms into &soul: nine patterns,
17 declared values and six degradation relations. The native audit exercises
23 positive causal applications and 31 contrary/unknown cases. Every pair
also blocks independently when either stabilizing partner is missing.
SoulBoot consumes both mechanical integrity and the native audit, so no
failed arm proceeds to soul-ready.

Orphan and dead-procedure fixtures fail the native rationality audit even
when the hash input is deliberately bypassed to isolate that consumer.
Separate loaded-atom and source-only tampering fail the integrity check.
The independent shell verifier checks every source byte hash and the sorted
loaded-atom manifest digest, then compares those to the actual runtime report.
Malformed output and missing-pin inputs return explicit errors.

First-pass evidence records a caught Unicode hashing error: the helper used
decoded-text hashing instead of encoding(octet). Subsequent preserved passes
exposed SWI 10 JSON's default # dictionary tag versus constructed anonymous
tags. A minimal probe demonstrates that equivalent JSON is not Prolog variant
equality. Final comparison uses deterministic JSON serialization, not those
incidental Prolog tags. No failed pass was committed as a success.

The nine descriptions are expressly bounded PoC projections, sourced to the
original architecture and current Constitution. They are not a claim to the
unavailable full v1.4 compass or the final mathematics of Soul. The authority
manifest pins doctrine, native consumers, integrity mechanics and source docs.
The native procedures test obligation standing; later certificate construction
must establish witnesses, rather than trusting arbitrary asserted symbols.

G13 establishes an immutable baseline and startup check. It does not claim
that arbitrary code in the trusted PeTTa process is sandboxed; G23/G27 must
prove candidate isolation. No runtime Soul writer is added to Miter's API.
No Python, service mutation, protected-file edit or licensed-data copy occurred.
Existing legacy services were left running. Raw timing is recorded; macOS
denied the sandbox's additional RSS/sysctl metrics.
